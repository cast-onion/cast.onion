# CDN Service

The CDN service is to display content including files like images, executables, audio, video, etc.

This can be accessed as http://localhost:1050 introducintg you to the welcome message.

## Test Endpoint

To test this endpoint, you can go to http://localhost:1050/dankFix.png to preview an PNG file.

## How To Make a File Accessable Through CDN

To make a file of yours accessable through the CDN service, add a file in cdn-files.
